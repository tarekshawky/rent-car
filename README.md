🖥️ Admin Dashboard

This project includes a secure admin dashboard built with Next.js, NextAuth, and Prisma. Admins can manage users and view account details.

🔐 Features
Authentication via NextAuth Credentials Provider
Session management using JWT
Create new admin users from the dashboard
View and edit profile information
Protected admin routes (/dashboard)
